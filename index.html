The Problem

Most AI tools treat everything like a Feature. It usually isn't.

When a broad business request goes straight to story generation, you get stories that get written, contested in refinement, and rewritten — because the scope was never properly defined. The real problem isn't writing stories. It's knowing when you're ready to.

✗ What other tools do
Generate stories immediately
Paste any request, get user stories back in seconds. Sounds fast. Creates chaos in refinement because the Epic was never scoped, the initiatives were never identified, and the scope was never agreed.
✓ What Prescope does
Classify first. Decompose progressively.
Every request is classified before anything is generated. Epics become initiatives. Initiatives become features. Features become stories — with acceptance criteria, assumptions, dependencies, and process flow diagrams built in.
How It Works
